## 0. 一页速查

### 0.1 两条设计谱系

| 谱系 | 核心命题 | 最强的东西 |
|---|---|---|
| **《冰与火之歌》龙类**（Drogon 等） | **"远看先读成龙"**：巨翼 + 长颈 + 长尾构成一个不可能认错的剪影 | 蝙蝠状膜翼、S 形长颈、箭头头骨 + 后掠角、数字行走后腿、带刺长尾、深色鳞甲 + 发光眼/喉 |
| **灾变 Mod Boss**（L_Ender's Cataclysm） | **"剪影第一、细节第二"**：极大体量 + 层叠甲 + 发光弱点 + 每只一个记忆符号 | 夸张肩甲/巨臂、层叠甲片、发光裂缝/核心、负空间、悬浮碎片、慢而重的待机 |

### 0.2 六条通用升级手法（本项目统一采用）

1. **剪影优先**：先定外轮廓（翼/角/肩/驼峰/披风），再填细节；64px 缩略图必须能认出是谁。
2. **层叠甲片**：2~3 层叠加、允许不对称、瓦片式覆盖，避免"一整块方盒子"。
3. **发光弱点**：眼/胸核/裂缝/符文——每只 1~3 处，配 `_glow.png` + `RankGlowLayer`，发光面积 4%~10%。
4. **负空间**：翼指间的膜、肋骨间隙、悬浮缝隙、袍摆开衩——"空"让体量看起来更大。
5. **悬浮碎片**：环、石板、晶片离体 1~3px，制造"巨物不受重力约束"的压迫感（法相/虚空系专属）。
6. **慢而重的待机**：呼吸（xScale/zScale ±1~2%）、摆翼、转头、尾摆、下颌开合；**绝对赋值，禁止 `+=`**。

## 1. 《冰与火之歌》龙类解剖（六个构件，逐个拆成方块模型做法）

> 参考对象是"龙"这个**视觉原型**，不是某个具体镜头/素材；以下全部是可复用的造型语言。

### 1.1 长而 S 形的颈（3~4 节，节长 12~18px）

- **为什么好看**：长颈把"头"和"身体"在剪影上拉开距离，形成 S 形引导线；俯视时头部悬在身体前方，天然带压迫感。
- **方块做法**：3~4 节盒（每节 10~18px 长），相邻节 pivot 串联，`setupAnim` 里做低频 S 摆（xRot/yRot 小幅度、相位错开）。
- **本项目**：虚空龙帝用 3~4 节（颈根 18px → 颈中 16px → 颈前 14px → 头 38×30×50）；恶·上身用短粗颈（巨颅直接压在胸上，走"巨神"而非"龙"的谱系）。

### 1.2 箭头状带后掠角的头骨

- **为什么好看**：箭头轮廓（吻部尖、眉骨高、后掠角）让头"像武器"；正面看是三角，侧面看是流线。
- **方块做法**：头骨主体 + 吻部（前伸）+ 眉骨（左右各 1）+ 上下颚 + 12 颗牙 + 后掠大角（2 根，各 3 节，向后上方）+ 颊刺（4 根）。
- **本项目**：虚空龙帝（双角 3 节 + 4 颊刺 + 12 牙）；万兽之主（巨角 2 支 + 8 獠牙 + 可开合下颚——兽类版本）；仙庭之主（冕旒冠 + 三眼，帝王版本）。

### 1.3 巨大的蝙蝠状膜翼（肩-肱-前臂-4 根长指 + 指间膜）

- **为什么好看**：翼是"体量放大器"——翼展一拉开，体型在玩家眼里直接翻倍；翼指间膜形成大面积负空间。
- **方块做法**：肩甲 → 肱（上臂）→ 前臂 → **4 根指骨**（每根 2~3 节、扇形张开）→ 指间膜 = 1px 薄板（4~6 片，深色/半透）；左右可轻微不对称（更自然）。
- **本项目**：虚空龙帝（翼展目标 14~16 格 = 站高 7 格的 2 倍以上）；虚空道主用"6 片悬浮翼片"做**灾变化**的翼（每侧 3 片、离体悬浮 1~3px、分节）。

### 1.4 数字行走的后腿 + 爪

- **为什么好看**：后腿让"龙"站起来而不是趴着；大腿-小腿-足三段 + 3 爪形成稳定三角，剪影有力量感。
- **方块做法**：大腿（粗、斜）→ 小腿（细、反关节）→ 足（3 爪着地）；脚底 y=24 保证站得住。
- **本项目**：虚空龙帝 2 后腿 + 2 小前爪；万兽之主 4 足（前肢肩甲+3 爪、后肢大腿/小腿/爪）；血魔老祖的"腿"藏在 3~4 层血袍下（只露脚）。

### 1.5 长尾 + 尾鳍骨刺

- **为什么好看**：长尾把剪影往后拉长，平衡前倾的颈；尾刺增加危险感，也让"尾摆"动画有看点。
- **方块做法**：4~5 节逐渐收细，背鳍刺 6~8 根，尾尖可加"刃/锤/晶刃"。
- **本项目**：虚空龙帝（4~5 节 + 6~8 背鳍刺 + 尾尖虚空晶刃）；万兽之主（4 节 + 尾锤）；血魔老祖（兽尾）。

### 1.6 材质与光

- **深色鳞甲三阶**（暗/中/亮）+ **翼膜半透/深色** + **眼与喉部发光**：龙类"生物感"的关键是"身体很暗，发光点很亮"。
- **方块做法**：主贴图三阶明暗 + `_glow.png` 只画眼/喉/裂纹；发光面积控制在 4%~10%。
- **本项目**：虚空龙帝（紫黑鳞 + 骨白角牙 + 青色发光裂纹/眼/喉 + 翼膜暗红半透）；焚天炎帝（黑曜+熔岩橙裂缝/胸核/眼）。

## 2. 灾变 Mod Boss 设计法（六条，逐条给"可检查标准"）

### 2.1 剪影优先（Silhouette First）

- **做法**：先只用大块（躯干/翼/角/肩/尾）摆出外轮廓，缩到 64px 判断"能不能认出是谁"；细节最后加。
- **检查**：64px 剪影与其它 Boss 两两 IoU < 0.70；单看剪影能说出"这是谁"。
- **本项目**：6 只全部按此流程；`round6/**/g1_剪影64.png` 为证据。

### 2.2 层叠甲片（Layered Plates）

- **做法**：甲片 2~3 层，内层暗、外层亮，边缘可加金饰/骨刺；允许左右不对称（更"活"）。
- **检查**：每只 Boss ≥2 处层叠结构（肩甲/胸甲/袍摆/骨板/甲裙）。
- **本项目**：焚天炎帝重肩甲 2~3 层 + 骨刺；血魔老祖胸甲 + 3 层血袍；仙庭之主 3 层披风/袍摆；万兽之主驼峰骨板 3 排。

### 2.3 发光弱点（Glowing Weak Point）

- **做法**：每只 Boss 设计 1~3 个"亮"的地方：眼、胸核、裂缝、符文、熔炉格栅；用 `_glow.png` + `RankGlowLayer` 渲染；发光面积 4%~10%，不能全身亮。
- **检查**：`_glow.png` 尺寸与主贴图一致；游戏内夜里能看出弱点位置。
- **本项目**：龙帝（眼/喉/脊椎裂纹）、炎帝（熔炉胸核/眼/关节/背管）、万兽（眼/肋骨/胸口核心）、血魔（血眼/血核/刃口）、道主（独眼/符文/裂纹）、仙庭之主（日轮/眼/冠饰）、恶（全身 24 眼 + 主眼）。

### 2.4 负空间（Negative Space）

- **做法**：故意"漏空"——翼指间膜、肋骨间隙、袍摆开衩、肩甲与躯干之间的缝、悬浮碎片与本体之间——让巨大体量有"呼吸感"，也让细节能被看见。
- **检查**：每只至少 2 处明显透空/缝隙；剪影里能看到"洞"而不是一坨。
- **本项目**：龙帝（指间膜 + 肋骨）、万兽（外露肋骨 + 驼峰间隙）、血魔（肋骨 + 六臂间空）、道主（悬浮翼片 + 布幔开衩）、恶（8 根外露肋骨 + 触须间空）。

### 2.5 悬浮碎片（Floating Fragments）

- **做法**：环、石板、晶片、符文离体 1~3px，`setupAnim` 里做错相浮动；用于"法相/虚空/神性"型 Boss，制造"不受物理约束"的压迫感。
- **检查**：悬浮件离体距离稳定（不穿模/不掉队）；动画相位错开。
- **本项目**：虚空道主（6 片悬浮翼 + 3~5 块悬浮符文石 + 背后虚空环）；仙庭之主（背后日轮/光轮 + 悬空玉圭/宝珠）。

### 2.6 慢而重的待机动作（Slow Heavy Idle）

- **做法**：呼吸（xScale/zScale 1%~2%）、摆翼/摆臂（低频）、转头（`netHeadYaw/headPitch` 微转）、尾摆/触须波动、下颌开合；幅度小、周期长（4~8 秒），**全部绝对赋值**。
- **检查**：静止 5 秒内能看出"它在呼吸/动"，但不会抖成筛子；`setupAnim` 无 `+=`/`*=`。
- **本项目**：6 只全部有呼吸/摆翼/转头/尾摆至少两类；恶还有 24 眼分 5 组眨眼、触须多相位。

## 3. 两种语言合成：本项目 7 条落地规则

| # | 规则 | 判定方法 |
|---|---|---|
| 1 | **剪影第一**：外轮廓优先，细节必须服务轮廓 | 64px 剪影能认出 + 与其它 Boss IoU < 0.70 |
| 2 | **每只一个符号**：一只 Boss 只主打一个记忆点（翼/熔炉/驼峰/三头/独眼/日轮/巨神） | 路人能在 3 秒内说出"它最显眼的是什么" |
| 3 | **发光纪律**：每只 1~3 处发光，4%~10% 面积，配 glow 层 | 夜里截图看弱点是否可辨 |
| 4 | **负空间预算**：每只 ≥2 处透空/缝隙（膜、肋、袍、悬浮） | 剪影里不出现"实心大方块" |
| 5 | **体量跳跃**：重做必须显著变大（站高 +50% 以上或翼展 ×2），不能只改细节 | before/after 数字对比（`工程/22`） |
| 6 | **不对称**：层叠甲/翼/碎片允许轻微不对称，避免"镜像呆板" | 目测左右不完全一致 |
| 7 | **动画可读**：待机动作慢而重，攻击动作大而可预判；全部绝对赋值 | 静止/移动各录 5 秒不穿模、不抖动 |

| 项 | 落地 |

## 6. 参考与出处说明

- **《冰与火之歌》龙类**：仅借用"龙"这一**视觉原型**的解剖语言（长 S 颈/箭头头骨+后掠角/蝙蝠膜翼/数字后腿+爪/长尾+尾刺/深色鳞+发光喉眼）；不复制任何具体镜头、模型或素材。
- **灾变 Mod 设计法**：仅提炼通用设计原则（剪影优先/层叠甲/发光弱点/负空间/悬浮碎片/慢重待机/每只一个符号）；不复制其任何模型、贴图、代码。
- 本项目所有模型均为 **spec → studio build_entity** 程序化生成（`工程/角色设计/round6/<boss>/spec.py`），贴图程序化绘制，无外部素材。
- 本手册的"目标数字"取自 `工程/21-Boss模型重制契约.md` §2；"实际 after 数字"见 `工程/22-Boss模型重制交付.md`（以最终代码/round6 模型数据为准）。

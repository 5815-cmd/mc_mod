## 2. 结构（按契约 §2E）

- **无腿下摆**：三层法袍布幔（y 8~24）+ 内层暗影 + 背后垂布；4 片垂摆布幔（hem_f/b/l/r）+ 6 条虚空触须 + 2 条两节长触须，全部收束到 **y=24**（浮空基准，最底点精确 24）。
- **层叠法袍躯干 3 层**：内袍（robe_purple 30×22×12）+ 外袍层（robe_blue 32×18×14）+ 前襟布幔与背部发光脊；胸口**虚空核**（发光）、2 根肋骨、金色腰封。
- **宽肩甲**：左右各 2 层肩甲 + 1 根虚空肩刺（外轮廓拉到 ±26px）。
- **独眼头**：28 宽巨颅 + 眉脊/下颚 + **18×10 巨眼（glow）+ 移动瞳孔（glow）+ 上下眼睑（会眨）** + 金眼眶四边 + 额头三层金冠 + 双角 + 颅后 3 条触须 + 颅顶骨刺 + 2 条发光裂纹（二/三阶段显形）。
- **6 片悬浮翼片**：每侧 3 片（扇开 0.62 / 0.20 / −0.26 rad），每片 **3 节**（a/b/c），节间 2px 离体悬浮（挂点仍 ≤3px，审计 0 断开）；翼片加厚到 6px 以读作"翼"。
- **4 条手臂**：2 长（肩->肘->手，18/14/12 节）+ 2 短（10/8），各持一把**虚空晶刃**（发光）；手臂长度受控，不垂到 y=24 以下（浮空模型的地面基准留给袍摆）。
- **悬浮符文石 4 块**（石头 + 发光符面）+ **背后虚空环**（8 段金环 + 4 块发光符面）。

## 4. 动画（setupAnim，全部绝对赋值）

- **悬浮上下 ±2px**：`waist.y = 4 + 2·sin(t·0.05)`（腰以上整体浮动，裙摆不动）；
- **翼片错相浮动**：18 个翼节各自 zRot/xRot 用不同相位正弦（6 片 × 3 节），并随阶段 `spread=1+0.16·(phase-1)` 张得更开；
- **独眼瞳孔移动**：`pupil.x/y` 双频正弦游走 + 瞳孔缩放；`eye` 随阶段放大；
- **眨眼**：每 96t 一次（7t 开合），上下眼睑 y 位移 + 横向拉伸；
- **法袍摆动**：4 片垂摆布幔、6 触须、2 长触须错相摆动；
- **头颈跟随**：`head.yRot = yaw*0.75`、`head.xRot = −pitch*0.55`、`neck` 少量；
- **手臂**：长臂主攻向外张合、短臂护体反相缓慢摆动；
- **符文石**：4 块绕体公转（半径 24~32）+ 自旋、上下小幅浮动；
- **虚空环**：慢速公转 + 轻微俯仰摆动；
- 阶段 2/3：裂纹显形、独眼/晶核放大、翼/臂展开更大（同一套模型，不换模型）。

## 2. 结构（契约 §2D 三识别点）

1. **三颗头**：
   - 中央主头 `head_mid`：16×16×16（最大），**冕冠**底座 18×5×18 + 5 根骨冠刺（顶到 y=-72 → 96px 高），
     双角各 2 节（静态外倾），**3 只发光血眼**（双主眼 + 额心竖眼），下颚 + 4 牙 + 2 獠牙；
   - 左右小头 `head_l/head_r`：12×14×14，各 2 节角、2 只发光眼、下颚 + 2 牙；由 `side_neck_l/r`
     颈根连到胸顶（挂点连续）——三头在同一高度带错落，正面/侧面都能数出「三颗」。
2. **六条手臂**（左右各 3，姿态错落）：
   - 上抬臂（`arm_u1_*`，StaticRot ±0.55）+ **血刃**（18px 刀身 + 1px 发光刃口）——共 2 把；
   - 平伸臂（`arm_u2_*`，±0.15）**张爪**（2 指）；下垂臂（`arm_u3_*`，∓0.35）**握爪**（2 指）；
   - 每条臂 上臂→前臂→(手/刃) 三段，肩/肘/腕均可动。
3. **躯干 + 袍摆 + 背部**：
   - 宽胸 26×24×16 + 领甲 + 2 层前胸甲 + **发光血核**（10×10×3 前凸）+ 左右各 3 根**外露肋骨**；
   - **巨型层叠肩甲**（每侧 2 层 + 3 根骨刺，外沿 ±32 = 64px 肩宽）；
   - 下半身血袍/裙甲 **4 层**（24→30→34→40px 逐层外扩，下摆到 y=24；双脚 `foot_l/r` 藏于袍下）；
   - 背部：骨刺脊 1 板 + 6 根骨刺、**蝠翼残片**（骨 2 节 + 1px 膜）、**血雾薄板** 2 片（前后各一）。

## 4. 动画（`setupAnim` 全部绝对赋值，禁止 `+=`/`*=`）

- **三头错相微转**：主头 `yaw*0.8`；左右小头 `yaw*0.45 ∓ 0.30`，各带 2.1 rad 相位差的呼吸/侧倾；
- **六臂缓慢张合**：三条臂 `open1/2/3` 相位错开（0 / 1.4 / 2.8 rad），出手时上抬 + 前压；
- **袍摆浮动**：4 层裙甲 `zRot` 相位逐层滞后（0.6/1.2/1.8 rad），下摆幅度最大；
- **血核脉动**：`xScale/yScale/zScale = 1 + sin(t*0.25)*0.10`（比其它 Boss 更快的心跳）；
- **蝠翼残片/血雾薄板**：骨与膜错相摆动、雾板 `yRot ±0.10` 漂移；
- 受击后仰 / 死亡前扑 + 下沉；胸甲呼吸（`xScale/zScale`，不动 y）。

## 6. 已知限制 / 偏差

1. **站高 97.1px**（6.07 格）比契约 96px 高 1.1%：来自冠冕中心骨刺 + 角的旋转，仍在 ±15% 容差内。
2. **渲染高度 ≠ 模型高度**：`BloodDemonRenderer.scale()` 保留原有 `×1.10`，BOSS 品阶 `scaleY()=1.12`
   → 实机约 6.07×1.12×1.10 ≈ **7.5 格**（hitbox 未动，audit 只记 hitbox 高度警告，不是硬问题）。
3. 离线审计（UV/洞/脚底/挂点）≠ 实机验证：动画穿模、发光观感、实机镜头需 Lead javac/build 后由用户看。
4. spec 中 4 层裙甲 24→40px 外扩是 UV 预算折中后的值（256² 装 113 盒已接近上限；再大需 512² 或减盒）。

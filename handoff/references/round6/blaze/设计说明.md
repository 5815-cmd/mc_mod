# 焚天炎帝 → 熔岩泰坦（Blaze Emperor / Lava Titan）· 第六轮 Boss 重制 B

> 契约：`工程/21-Boss模型重制契约.md` §2B（灾变风：大体量 / 层叠甲板 / 发光内芯 / 夸张肩甲巨臂）。
> 生成链：`round6/blaze/spec.py` → `tools/build_entity.py`（studio 的 UV 装箱 + Java 生成 + 贴图 + 发光层 + 审计）。
> 一句话：**从"矮胖方块人"重做成黑曜石外壳的熔岩巨神**——胸口 28×28 发光熔炉、层叠巨肩甲+骨刺、
> 双臂三节+巨拳、牛角冠+火焰鬃毛+发光眼、背部排气管+熔岩喷口。
> 叙事符号：**远看=肩宽 4.5 格的熔炉巨人，近看=胸口熔炉格栅在呼吸**。

## 1. 硬指标（契约 §2B）

| 项 | 契约目标 | 实测 | 判定 |
|---|---|---|---|
| 站高 | **6.0 格（96px）** | **96.0px**（蹄底 y=24 → 角尖 y=-72） | ✅ 精确 |
| 肩宽 | **4.5 格（72px）** | **72.0px**（肩甲外缘 x=±36） | ✅ 精确 |
| cube | **≥80** | **118**（32 个部件） | ✅ |
| 贴图 | **256×256** + `_glow.png` | 主图 256²（41916 不透明纹素）/ 发光 256²（1995 纹素） | ✅ |
| 类 API | 类名 / `createBodyLayer()` / 构造器不变 | `BlazeEmperorModel extends EntityModel<CultivationMonsterEntity>` + `(ModelPart root)` + `createBodyLayer()`（`LayerDefinition.create(mesh,256,256)`） | ✅ |
| `LOWEST_PIXEL_Y` | 补 `24.0` | `public static final double LOWEST_PIXEL_Y = 24.0;`（另有 `HIGHEST_PIXEL_Y=-72.0`、`SHOULDER_WIDTH_PX=72.0`） | ✅ |
| Renderer | 无 glow → 加 `RankGlowLayer` | `BlazeEmperorRenderer` 构造器 `addLayer(new RankGlowLayer<>(this))`，发光贴图按 `<贴图>_glow.png` 规则自动定位 | ✅ |
| 不改 | LAYER / ClientSetup / 实体 / hitbox | 均未改（`ClientSetup` 仍用 `BlazeEmperorRenderer.LAYER` + `BlazeEmperorModel::createBodyLayer`） | ✅ |

**UV 预算**：box 足迹 = `(2d+2w)(d+h)`（≈表面积 + 2d²，深度最贵）。256²=65536，
本模型总足迹 **48,788（74.4%）**，`pack_uv` 逐格贪心装下（此前 118 cube/101k 足迹的初稿装不下，
按"剪影优先、薄板压到 1~4px、深部压到 8~12px"重排后通过）。

## 3. 动画（`setupAnim`，全部绝对赋值，无 `+=`/`*=`）

| 组 | 实现 |
|---|---|
| **熔炉呼吸** | `torso.xScale/zScale` 脉动（阶段越高幅度越大，`entity.bossPhase()` 1/2/3 → rage 0.3/0.6/1.0）；`furnace.xScale/yScale/zScale` 核心脉动（±4.5%~7.5% + 受击）；`ventL/R` 错相 ±5% |
| **双臂展开-握拳** | 攻击 `entity.getAttackAnim`：`armL/R.zRot` 向两侧展开（0.70~0.85 rad，阶段加成）；`swing`/`clench` 双曲线；`fistL/R.xScale/zScale` 收拳 10%；`fingersL/R.xRot` 内扣 0.9 rad |
| **头部缓慢环视** | `head.yRot = netHeadYaw*0.4 + 0.22*sin(t*0.017)`（慢速左右扫视）；`head.xRot` 俯仰 + 攻击低头；`jaw.xRot` 呼吸开合 + 攻击张开 |
| **肩甲上下** | `pauldronL/R.y` ±0.6px 错相起伏 + 攻击后张 ±0.8px；第二层 `pauldronL2/R2.y` 再错相 ±0.4px |
| 其他 | 整身呼吸步频（`hips.y`）、粗腿慢步（`thigh/shin/hoof` xRot，幅度小="重量感"）、鬃毛/金冠微摆、背管脉冲、腰链摆动、死亡塌陷（xRot/scale 收） |

## 7. 偏离项与已知限制

1. **巨拳尺寸 24×24×20**（契约写 `24×24×28`）：256² 贴图装不下初稿（118 cube/101k 足迹），
   把拳深 28→20（宽/高保持 24）后总足迹降到 48.8k 通过。视觉上仍是"齐腰巨拳"，
   契约的"巨拳"意图保留；若 Lead 要求严格 28 深，需要 512² 贴图或砍其它 30+ cube。
   同理若干贴边薄板（金饰/肋甲/胫边）压到 1~4px 厚、躯干/腿/臂的深度压到 8~12px —— 均为 UV 预算。
2. **模型比旧 hitbox 大**（6.0 格 vs 旧 3.7 格）：契约 §1 允许（audit 只记警告），
   实体/hitbox 按要求未改；实机中受击判定仍是旧尺寸（Lead 若需要可另行调 hitbox）。
3. **未跑 gradle/javac**（任务禁止）：已核对生成代码的类 API/字段（33 个 ModelPart 字段、
   动画引用的 30 个字段全部存在）、`LayerDefinition.create(mesh,256,256)`、
   `RankGlowLayer` 单参构造器（项目内已有 6 处同样写法），最终以 Lead javac 为准。
4. **离线渲染≠实机**：证据图是 renderlib 软件光栅 + 近似光照；发光层亮度/雾效以客户端为准。
5. 贴图 256×256 是从旧 128² 升级（契约要求），旧贴图文件已被覆盖（git/构建缓存外无备份）。

## A. 物品与装备体系

### A.1 槽位与品类：主流修仙 mod 怎么分装备

**✅ 查证：凡人修仙人界篇的装备品类**（[来源](https://www.mcmod.cn/post/3093.html)）

| 品类 | 具体形式 | 承载槽位 | 例子 |
| --- | --- | --- | --- |
| 主武器·近战 | 剑 / 刀 / 锤 / 爪 / 拳套 | 主手 | 桃木剑、血木剑、解牛刀、撼地锤、裂虎爪、石峰拳套 |
| 主武器·远程 | 弓 / 飞针 / 弹丸 | 主手 | 混沌战弓、追魂针、霹雳弹、腥毒短刀 |
| 法器（法术媒介） | 扇 / 幡 / 棋 / 珠 / 葫芦 | 主手 | 飓风扇、流火幡、天行棋、燃焰珠、覆火葫芦 |
| 飞行法器 | 剑（可骑乘飞行） | 主手 | 青锋剑 |
| 防具·法袍 | 套装（头/胸/腿/靴） | 四件套 | 悟道袍、乾坤八卦袍、阴阳两仪袍 |
| 防具·护甲 | 套装 | 四件套 | 锁子黄金甲 |
| 副手 / 护心镜 | 盾 / 环 | **副手** | 碧海无量盾（+268 物防，每 5 秒抵消一次攻击）、金玉环（+8 法防，每秒回 1 气血） |
| 符箓（消耗品·伤害） | 符箓 / 符宝 / 真宝 三档 | 主手右键 | 飞剑符宝、五雷符 |
| 储物袋（掉落容器） | 按境界分级的战利品袋 | 背包物品 | 练气散修储物袋、结丹魔修储物袋、通天教主储物袋 |

**✅ 查证：凡人修仙的符箓三分档**（[来源](https://www.mcmod.cn/post/2679.html)）

| 档位 | 使用次数 | 伤害定位 |
| --- | --- | --- |
| **符箓** | 一次性 | 伤害中规中矩 |
| **符宝** | 可多次使用 | 伤害略低于对应法宝；制作会消耗法宝耐久 |
| **真宝** | 一次性 | **伤害巨大** |

**✅ 查证：Iron's Spells 的槽位设计**（[iron.wiki/armor](https://iron.wiki/armor/) / [curios](https://iron.wiki/curios/) / [spellbooks](https://iron.wiki/spellbooks/)）

Iron's 把「法术书」独立成 **Curios 饰品栏的一个专属槽位**（3.0.0+ 版本起，法术书必须装备到饰品栏才能施法，手持无效），主手则交给法杖提供加成。这是一条非常值得抄的设计：**施法媒介（书）与加成媒介（杖）分离**，两个槽位各司其职。

**✅ 查证：修仙之路的饰品槽清单**（[来源](https://www.mcmod.cn/class/29174.html)）

> 可使用的饰品槽包括：**发型、发饰、头饰、项链、内衣、披风、背饰、腰饰**。
> 部分装备：道服胸甲、棺材背饰、旗帜背饰、蒙眼布、斗笠、**玉佩**、镇魂铃、引魂锣。
> 玉佩可以提升打坐效率，镇魂铃与引魂锣则可以佩戴在腰饰槽中使用。

**🔶 推测建议：我们应采用的槽位方案**

| 槽位 | 承载物 | 设计理由 |
| --- | --- | --- |
| 主手 | 剑/刀/枪、法器、符箓 | 沿用原版，零成本 |
| 副手 | 护心镜、盾、玉佩、第二把飞剑 | 碧海无量盾证明副手能承载独立机制 |
| 头部 | 法冠 / 斗笠 / 蒙眼布 | 对应 Iron's 的"帽子类"独立外观 |
| 胸/腿/靴 | 法袍套装 或 护甲套装 | 二选一，形成"法修 vs 体修"分野 |
| **心法槽** | 功法书 | 对应凡人修仙"可学多本功法" |
| **法宝槽（3 格）** | 飞剑 / 葫芦 / 幡 / 印 | 对应凡人修仙"法宝常驻生效"（如意金箍棒"持有时每秒 260 点火伤"） |
| **戒指槽（2 格）** | 纳戒 / 储物戒 / 属性戒 | 对应纳戒 + Iron's Ring |
| **玉佩槽（1 格）** | 玉佩、护身符 | 打坐/修炼效率向 |
| 背部 | 剑匣 / 幡旗 / 棺材 | 纯外观 + 少量功能 |

> 建议用 **Curios API**（Iron's、纳戒均依赖它，见 [mcmod 2029](https://www.mcmod.cn/class/2029.html)）。

### A.2 装备品阶分级

#### A.2.1 主流的两种分级法

**方案一：按「境界」直接分阶（凡人修仙采用）** ✅ 查证

凡人修仙人界篇**不用**「凡器→灵器→宝器」这套名词，而是**直接用炼制者所需境界作为品阶**：

> 练气 → 筑基 → 结丹 → 元婴 → 化神
> 例：**练气**：覆火葫芦 / 燃焰珠 / 桃木剑 / 青锋剑；**筑基**：霹雳弹 / 青虹剑 / 解牛刀；**结丹**：飓风扇 / 天行棋 / 血木剑；**元婴**：燃山剑 / 石峰拳套 / 流火幡 / 追魂针；**化神**：撼地锤 / 混沌战弓 / 裂虎爪 / 雷击木剑
> 出处：[凡人修仙炼器篇](https://www.mcmod.cn/post/3093.html)

炼器玉简上会直接写明门槛：

> 「练气境界方可炼制，消耗 70 灵力值，练气期法器〔赋能〕攻击额外造成伤害。炼材:〔主〕桃木\*4 〔辅〕精血\*1 〔辅〕聚灵粉\*3。炼器:〔一〕级炼器鼎，〔一〕级异火」
> 出处：[凡人修仙炼器篇](https://www.mcmod.cn/post/3093.html)

**方案二：材质阶梯（Mystical Agriculture / Iron's 采用）** ✅ 查证

| 模组 | 阶梯 |
| --- | --- |
| Mystical Agriculture | Inferium → Prudentium → Tertium → Imperium → Supremium（+ 整合包追加 Insanium），**每级升级 = 4 个下级精华 + 1 个 Infusion Crystal**，因此 1 Supremium = 256 Inferium（[来源](https://craftdownunder.co/guides/mods/mystical-agriculture)） |
| Iron's Spells 法术书 | 铜（无加成）→ 铁（无加成）→ 金 → 钻石 → 下界合金 → 龙皮/独特（[来源](https://iron.wiki/spellbooks/)） |
| Ars Nouveau 法袍 | 初学者 → 法师 → 大法师（[来源](https://www.mcmod.cn/item/414849.html)） |

#### A.2.2 🔶 推测建议：我们的品阶体系

建议**双轨制**——对外显示修仙味的品阶名，对内用「境界序列」作为数值锚点（这是凡人修仙已验证的做法，玩家一看就懂，我们也省去平衡成本）。

| 品阶名 | 对应境界 | 装备数值锚点 | 获取方式 |
| --- | --- | --- | --- |
| **凡器** | 凡人 / 练气前期 | 原版铁~钻石之间 | 工作台直接合成 |
| **法器** | 练气 | 1.0× 本境标准值 | 一阶炼器鼎 |
| **灵器** | 筑基 | 1.0× | 二阶炼器鼎 |
| **宝器** | 金丹 | 1.0× | 三阶炼器鼎 |
| **法宝** | 元婴 | 1.0× | 四阶炼器鼎 + 附灵台 |
| **灵宝** | 化神 | 1.0× | 五阶炼器鼎 + BOSS 掉落 |
| **道器** | 道印 | 1.0× | 秘境 BOSS 掉落 + 炼器 |
| **仙器** | 飞升 / 仙人 | 1.0× | 天劫材料 + 仙人掉落 |
| **帝兵** | 帝境 | 1.0× | 帝境 BOSS 唯一掉落 |
| **鸿蒙至宝** | 鸿蒙 | 1.0× | 鸿蒙维度唯一产出 |

> 「本境标准值」的定义见 [D.2 节的伤害锚点表](#d2-我们的十境数值曲线推测建议)。**凡人修仙的实测规律是：同阶武器的附加攻击 ≈ 该境界标准伤害值的 1.0~1.4 倍**（详见 D.2）。

### A.3 强化 / 炼器 / 附灵系统怎么做

#### ✅ 查证：凡人修仙的完整工艺链

**炼器（装备制造）**（[来源](https://www.mcmod.cn/post/3093.html)）

1. 需要 **玉简**（配方载体）——列出材料 + 材料摆放顺序
2. 需要**火**（丹火或异火，**阶级必须与法宝同阶**）
3. 需要**炼器鼎**（等级要求与法宝同阶）
4. 需要**独立多方块结构**：火烤着上面的炼器鼎（结构不会爆炸，炼丹结构则会）
5. 材料按玉简顺序摆入 → 点击炼制 → 等待 CD → **有概率成功**
6. 产出的是「法器」，带 **〔赋能〕** 词条（例：桃木剑的赋能是"攻击额外造成伤害"）

**附灵（防具制造，独立于炼器）** ✅ 查证

防具走 **赋灵台**，而不是炼器鼎：

| 品阶 | 套装 | 属性 | 赋能 |
| --- | --- | --- | --- |
| 练气 | 悟道袍套装 | 3 物防 / 6 法防 | 穿戴后每秒回复 1 气血 |
| 结丹 | 乾坤八卦袍套装 | 30 物防 / 70 法防，10% 法防加成 | 每秒恢复 3 气血 |
| 化神 | 阴阳两仪袍套装 | 223 物防 / 646 法防，20% 法防加成 | 每秒恢复 5 灵力 |
| 化神 | 锁子黄金甲套装 | 716 物防 / 123 法防，20% 物防加成 | 每秒恢复 5 气血 |

出处：[凡人修仙炼器篇](https://www.mcmod.cn/post/3093.html)

**副职业技能等级（炼器/炼丹/画符/阵法各自独立升级）** ✅ 查证（[来源](https://www.mcmod.cn/post/2679.html)）

| 等级 | 1 级 | 2 级 | 3 级 | 4 级 |
| --- | --- | --- | --- | --- |
| 炼器升级经验 | 36 | 180 | 900 | 4500 |
| 画符升级经验 | 36 | 180 | 900 | 4500 |
| 阵法升级经验 | 36 | 180 | 900 | 4500 |
| **炼丹升级经验** | **1950** | **7650** | **38880** | **127980** |
| 支离 / 搜寻（掉落加成副职） | 500 | 1500 | 4500 | 13500 |

> 注意数值设计上的巧思：**炼器/画符/阵法用同一套 ×5 递增曲线（36→180→900→4500）**，而**炼丹故意拉高 50 倍**，让炼丹成为一条明显更慢、更"专业"的路线。这是一种用数值做「职业分化」的手法。

**副职等级的作用** ✅ 查证：炼丹等级影响**丹药成功率**与**修为丹品质**（丹药本身不受等级限制，但会失败）。

#### ✅ 查证：Iron's Spells 的两套强化系统

| 系统 | 机制 | 覆盖面 |
| --- | --- | --- |
| **注魔 Imbuement** | 在**奥术铁砧**把 1 个法术注入剑 / 某些胸甲 / 黯淡皇冠。**一把武器只能注 1 个法术，不可取回** | 武器 + 胸甲 + 头盔 |
| **护甲升级 Armor Upgrade** | 用**升级法球 Upgrade Orb** 升级学派盔甲、法术书、法杖 | 全套装备 |
| **法术书升级** | 奥术铁砧 + 墨水（不同墨水决定法术等级） | 法术本身 |
| **戒指附魔可叠加** | **Ring of No Affinity**：随机提升某法术 +1 级，**该效果可叠加**，可在奥术铁砧用卷轴指定法术 | 饰品 |

出处：[iron.wiki 首页](https://iron.wiki/) / [curios](https://iron.wiki/curios/) / [mcmod 10175](https://www.mcmod.cn/class/10175.html)

**升级法球的材料链**也值得抄：`远古骑士掉落猩红源质（Cinder Essence）→ 制作升级法球`（[来源](https://iron.wiki/)）。即**终局强化材料绑定特定精英怪**，而不是绑定挖矿。

#### ✅ 查证：修仙之路的「文学化炼器」

> 炼器包含：**玉简配方、温度条、火焰温度、平均温度记录、炼制进度、材料纯度、熔炼时间、品质判定、淬火**。
> **不同材料会为武器提供不同词条。温度、材料比例、纯度和淬火时机都会影响武器成品。**
> 出处：[mcmod 29174](https://www.mcmod.cn/class/29174.html)

这是一套「**过程即玩法**」的炼器：同样的配方，因为温度和淬火时机不同，出不同词条的成品。**比凡人修仙的"概率成功"更有深度，更值得抄。**

#### ✅ 查证：Mystical Agriculture 的镶嵌式终局

> Supremium 工具和盔甲可接受 **Augments**（如飞行、夜视、范围挖掘），构成该模组的终局奖励线。
> 出处：[CDU 指南](https://craftdownunder.co/guides/mods/mystical-agriculture)

#### ✅ 查证：Apotheosis 的宝石镶孔

> **Gems** 可镶入装备提供属性（生命、暴击率、挖掘速度）；**sigils** 管理插槽本身。**重铸台**消耗材料重掷词缀，**分解**把不要的掉落拆成重铸燃料。
> 出处：[CDU 指南](https://craftdownunder.co/guides/mods/apotheosis)

**四条关键设计规律** ✅ 查证（[来源](https://www.mcmod.cn/post/2827.html)）：

1. **同一物种会在多个阶出现，用不同强度版本复用模型**（鹰枭出现在二/三/四/五阶；魂铁兽出现在一/二/三/四阶）。**极限复用美术资源**，这是小团队最该抄的一条。
2. **每阶都有「早/中/后期」细分**：一阶初期、一阶中期、一阶后期 → 表明阶内还有 3 个强度档。
3. **妖兽按地形刷**，不按维度刷：绿泥/寄魂蟹→桃林，雨蛙→文玉木林，魂铁兽/石巨人/军颚蚁→破碎山石岭，骨狼/蒲鸟/黑蛛→飞升之地，雷斑鹿/雷原巨鳄/守馆阴兵→雷击之地。**地形 = 怪物等级地图**。
4. **敌对 NPC 直接按玩家境界命名**：白天刷散修、夜晚刷魔修，等级跟随境界（练气→筑基→结丹→元婴→化神）；**结丹以上的散修/魔修改到地狱、末地、冥府生成**（维度即等级门槛）。

**掉落规律** ✅ 查证：
- 所有妖兽都**几率掉落对应等级的妖丹**（一阶妖丹、二阶妖丹……）→ 妖丹是跨系统的通用货币
- 每种妖兽还掉专属材料（绿泥→聚灵泥 40%，寄魂蟹→红阳精，魂铁兽→煞魂玉/魂铁，石巨人→附灵石原，雷斑鹿→雷斑鹿精血，白泽→白魄/幻源，九尾火狐→九色狐魄/混沌假丹，麒麟→麒麟血/辟邪假丹）
- 修士掉**躯壳**（练气躯壳/筑基躯壳/结丹躯壳/元婴躯壳/化神躯壳）+ **储物袋**
- BOSS **必掉专属储物袋**

> 「**对原版敌对生物进行了全面修仙化改造**」

### B.3 精英怪机制

#### ✅ 查证：凡人修仙的精英怪

精英怪**没有独立的词缀系统**，而是作为「境界 + 势力」的组合实体存在（[来源](https://www.mcmod.cn/item/list/8033-4.html)）：

| 精英怪 | 境界 | 生成地 |
| --- | --- | --- |
| 合欢宗精英 | 元婴初期 | 冥府秘境 |
| 合欢宗长老 | 元婴中期 | 冥府秘境 |
| 左护法 / 右护法 | 化神初期 | 天宫秘境 |
| 古老魔 | 化神中期 | 天宫秘境 |

**即：精英怪 = 秘境（地牢）里的守卫，比同阶普通怪高一个小境界，由"势力名 + 职位名"构成。** 这是一个几乎零成本的精英怪命名法。

#### ✅ 查证：Apotheosis 的词缀精英怪

> 怪物掉落 **affix items**——跨稀有度（common 到 mythic/ancient）的带随机词缀的武器与护甲。
> **稀有的 boss mobs 会带着公告名称生成，并携带更优战利品**——这是该模块在普通挖矿中的"调味料"。
> 出处：[CDU 指南](https://craftdownunder.co/guides/mods/apotheosis)

#### ✅ 查证：Iron's Spells 的精英怪生成方式

> **远古骑士（Ancient Knight）**：在**下界的「远古战场」结构里破坏盔甲残骸，有概率生成**。掉落**猩红源质（Cinder Essence）**，用于制作升级法球。
> 出处：[mcmod 10175](https://www.mcmod.cn/class/10175.html) / [iron.wiki](https://iron.wiki/)

即：**精英怪不必自然刷，可以作为"玩家主动触发的资源点"**——玩家砸残骸 → 出精英怪 → 打掉拿强化材料。这比随机刷怪更有掌控感。

## C. 难度系统参考

### C.1 做了「开局选难度并影响开局抽奖」的模组

#### ✅ 查证：凡人修仙人界篇 —— 最直接的样本

**① 进游戏弹难度选择器**（[来源](https://www.mcmod.cn/post/2679.html)）

> 「进入游戏会出现**难度选择器**，可根据自身情况选择」

**② 难度档位与数值影响**（[来源](https://www.mcmod.cn/class/version/8033.html)）

> 更新日志原文：「**难度选择里的简单、普通、困难、极难、随机**的功法需求减少从 95% 调整为 **80%**」

即 5 档难度：**简单 / 普通 / 困难 / 极难 / 随机**。

**③ 难度直接影响的核心数值 = 「功法修炼需求」**（[来源](https://www.mcmod.cn/post/2679.html)）

> 「难度选择器中**所有模式功法需求均为 5%**」
> 「**随机的功法需求为 100%**」
> 「（功法修炼需求指的是修炼功法层数的时间）」

**这是全文最关键的一条发现**：凡人修仙的难度**不是简单粗暴地乘怪物血量**，而是**调节"功法修炼所需时间"这一个乘数**——
- 简单/普通/困难/极难：功法需求 **5%**（即修炼速度 20 倍）
- 随机：功法需求 **100%**（正常速度，即慢 20 倍）

也就是说，**难度选择实质上是一个"成长速度倍率"，而不是"战斗难度倍率"**。这是一个更优雅的设计，因为它不改变战斗手感，只改变节奏。

**④ 灵根抽奖（开局 Roll 点）**（[来源](https://www.mcmod.cn/post/2679.html)）

> 「**灵根的数量会影响自身的灵力上限、回灵，同时真元需求提高，每多一个灵根突破概率减少 5%**，结丹境界开始所有数量的灵根所需的真元需求一样。」
> 「**寿元没有后会刷新灵根体质**，练气之后则会保留灵根体质和境界（只有在寿元没有时，会重归凡人）。寿元每半小时减少 1 寿元。」

即：**灵根是一个"多 = 强但更难突破"的权衡（trade-off）**，不是单纯的稀有度抽奖：
- 灵根多 → 灵力上限高、回灵快 → 强度高
- 灵根多 → 每多 1 个突破概率 −5% → 更难过关

**⑤ 属性界面按键**：`K` 键打开属性面板，查看血量 / 真元 / 灵气 / 煞气 / 灵根 / 境界 / 副职业等级 / 已学功法（[来源](https://www.mcmod.cn/class/8033.html)）

#### ⚠️ 二手：某国产修仙模组（清风工作室）—— 难度 → 随机灵根 + 随机器运 → 发初始道具

> 「进入游戏后，我们首先要**点击左上角的太极**，然后进行**难度选择**，之后会进入一个**随机灵根和随机器运的界面**，选择完成之后会**根据你的气运和灵根给予一些基础道具**，比如我现在获得了三十个灵石，还有一把钻石镐和千灵万脉镐」
> 出处：[抖音视频描述](https://www.douyin.com/shipin/7306431236787685428)

**这是对用户需求"开局选难度并影响开局抽奖概率"最直接命中的样本**，完整流程是：

#### D.2.4 十境怪物数值建议表（🔶，按 R5/R6 生成）

见 [B.5.2 节的完整表格](#b52-每境界的妖兽怪物属性模板-基于-实测规律推导)。核心公式：

```
本境标准伤害 D = 查 D.2.2 表
普通妖兽：HP = D × 5，主攻 = D × 1.0，护甲 = 2 + 境界序号 ÷ 2
精英怪  ：HP = D × 15，主攻 = D × 1.5，护甲 = 4 + 境界序号
BOSS   ：HP = D × 7 （注：BOSS 的 D 用"高一阶"的值，见下）
```

> ⚠️ **重要修正**：实测中「合欢宗老祖（元婴）的 HP 3247 = 元婴标准值 424 × 7.66」，但如果它是给**元婴期玩家**打的，那 424 就是玩家的输出基准，7.66 倍意味着**约 8 个满伤技能**能打死 BOSS。这在一场 2~3 分钟的战斗里是合理的（玩家还要走位、躲技能、吃血）。
> **建议**：BOSS 的 HP 倍率取 **×7**（= 约 8 次满伤技能），**不要取更高的值**，否则会变成"血包木桩"，丧失节奏感。

## G. 落地检查清单（给实现的同学）

按优先级排序，前 3 项是**所有被调研模组的最大公约数**，必须先做：

- [ ] **1. 全局「境界标准值」表**（D.2.2）：所有装备、怪物、法术的数值都从这张表派生，绝不硬编码。这是凡人修仙能保持 5 个境界数值不崩的根本原因。
- [ ] **2. 难度 Profile 数据结构**（C.3）：一个 `DifficultyProfile` 配置对象，装所有倍率；难度只影响「成长速度 + 突破成功率」，怪物数值改动要克制。
- [ ] **3. 开局三步流程**（C.2）：难度选择 → 灵根 Roll → 气运 Roll → 发道具 → 给引导物（神秘残页）。
- [ ] 4. 妖兽资源复用策略（B.1 规律 1）：同一模型做 3~4 个阶级版本，先做 6~8 个物种撑满 10 个境界。
- [ ] 5. 地形 = 等级地图（B.1 规律 3）：每个境界绑定 1~2 个生物群系/维度，玩家用脚投票选择难度。
- [ ] 6. 妖丹作为跨系统通用货币（B.1）：每阶妖兽都掉对应妖丹，炼丹/炼器/突破都用它。
- [ ] 7. BOSS 技能池（B.2）：低血狂暴 + 阶段转换 + 位移突进 + 持续 AOE，四个里挑 2~3 个。
- [ ] 8. 精英怪三层机制（B.3）：词缀精英（自然刷）/ 势力精英（结构守卫）/ 遗迹精英（玩家触发）。
- [ ] 9. 强化四层（A.3）：炼器 → 淬炼（温度/纯度/淬火）→ 镶嵌灵石 → 附灵。
- [ ] 10. 储物三件套（A.4）：储物袋（早期）/ 纳戒（戒指槽）/ 灵兽袋（收妖）。

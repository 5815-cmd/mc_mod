# 领域（本命领域）完善规格

> 玩家原话逐条落成，**数值一个都不能改**。这是 `docs/modpack-roadmap.md` 里
> 「最后做领域」的那一项。

---

## 一、领域范围

- 现状：**10 × 10 区块**（玩家认为太大）
- **改成 6 × 6 区块**

> 6×6 区块 = 96×96 格。仍然很大（视野内基本全覆盖），但比 160×160 合理得多。
> **做成配置项**，方便整合包里再调。

---

## 二、通用规则

### 2.1 默认无友伤

- 领域**默认不伤害友善生物**（玩家、驯服的宠物/坐骑、NPC）
- **在 `R` 界面（修行面板）里可以开关**

### 2.2 首领（OVERLORD）单独结算

**所有"秒杀"或"百分比"效果，对首领固定为掉血 2%。**

即：
| 效果 | 对普通怪 | 对首领 |
|---|---|---|
| 土的秒杀 | 直接秒（头目以下） | **2%** |
| 金的冲击波 30% | 30% | **2%** |
| 雷的三连 10% | 10% | **2%** |
| 冰的爆炸 10% | 10% | **2%** |
| 风的十次 10% | 10% | **2%** |
| 火的 1%/秒 | 1%/秒 | **2%**？→ **见下** |

> ⚠️ **需要澄清的一点**：玩家说的是"以上秒杀或者是百分比效果对首领的伤害都固定在掉血 2%"。
> 但火的 1%/秒、水的 1%/秒是**持续**效果，如果对首领也固定成 2%/次会**每秒 2%**
> （50 秒必死），比 1%/秒还高，逻辑上讲不通。
> **本规格按"每次结算固定 2%"实现**（即持续效果对首领也是每次结算 2%），
> 但**把这一点单独标出来**，如果玩家本意是"对首领的百分比效果封顶在 2%"，实现要改。

### 2.3 怪物境界区分

- **怪物也要有境界**（现在只有 5 档品阶，没有境界）
- **强力怪物最低也要对标"标准强度修为"**（不能低于 `RealmStats.standard(tier)`）
- **玩家境界低于怪物境界时，怪物有减伤效果**

> 实现要点：怪物已有 `MobScaling.realmScaleFor(Level, Entity)`（按玩家境界缩放）。
> 现在要给它一个**自己的境界**（进世界时按玩家境界或按副本门槛定），
> 然后 `玩家境界 < 怪物境界` → 怪物受到伤害乘以一个减伤系数。
> 减伤系数做成纯数据表，可离线断言。

## 三、八种元素的领域效果

> 玩家的道宫有元素属性（金木水火土 + 变异 冰雷风）。
> **领域按当前激活的道宫元素决定表现。**

### 3.1 火 —— 火雨

| 项 | 值 |
|---|---|
| 表现 | **下火雨** |
| 效果 | 怪物**被强制燃烧** |
| 秒伤 | **等同于泡在岩浆湖里**（岩浆每秒 4 点 = 2 心） |
| 附加 | **每秒 1% 最大生命** |

### 3.2 木 —— 地下生藤缠绕后爆刺

| 阶段 | 值 |
|---|---|
| 1. 缠绕 | 地下长出植物**缠绕怪物** |
| 2. 延迟 | **5 秒后**植物**爆炸** |
| 3. 爆炸伤害 | **5 点**（2.5 心） |
| 4. 木刺 | 向四周发射木刺，每根 **1% 生命** |

### 3.3 水 —— 涨潮

| 项 | 值 |
|---|---|
| 表现 | **下雨 + 涨潮**，湖水上升**覆盖地面** |
| ⚠️ 限制 | **只是特效**，**不破坏实际物品、不影响火把与作物** |
| 效果 1 | 怪物**水下窒息**（受窒息伤害） |
| 效果 2 | 怪物**减速** |
| 附加 | **每秒 1% 最大生命** |

### 3.4 金 —— 锐利之气 + 五层标记

| 项 | 值 |
|---|---|
| 表现 | 产生**锐利之气**（特效） |
| 效果 | **持续打击**怪物，每次 **3 点**（1.5 心） |
| 标记 | 每次叠加**一层特殊标记** |
| 爆发 | **5 层后**以**角色为半径**产生**锐利冲击波** |
| 冲击波伤害 | 怪物掉 **30%** |

### 3.5 土 —— 束缚拖入地中

| 项 | 值 |
|---|---|
| 效果 1 | 怪物**被束缚，不能移动** |
| 效果 2 | **仍可远程攻击**玩家 |
| 效果 3 | **离得近也会被近战摸到**（即玩家仍能打到它、它也能被近战命中） |
| 效果 4 | 怪物被**缓慢拖入土中** |
| 时限 | **10 秒内**完成这个动作 |
| 结果 | **秒杀头目以下的怪物**（品阶 < BOSS） |
| 首领 | **单独计算 → 2%** |

### 3.6 冰 —— 冰冻后爆裂

| 项 | 值 |
|---|---|
| 1. 冰冻 | **5 秒** |
| 2. 延迟 | 冰冻后 **3 秒**爆炸 |
| 3. 持续 | 领域内怪物**持续减速 + 持续掉血（一次 1 点）** |
| 4. 爆炸 | **10% 伤害** |

### 3.7 雷 —— 周期雷击 + 三连

| 项 | 值 |
|---|---|
| 周期 | **每 3 秒**劈一次 |
| 单次伤害 | **5 点**（2.5 心） |
| 三连 | 每第 **3 次**被雷劈 → **同时被 3 道雷劈** |
| 三连伤害 | 基础 **15 点** + **10% 生命** |

### 3.8 风 —— 高频斩击 + 十次爆发

| 项 | 值 |
|---|---|
| 表现 | **一直斩击**怪物 |
| 每击 | **2 点**（1 心） |
| 频率 | **要比其他元素高一些**（明确要求） |
| 爆发 | **命中 10 次后**造成 **10% 伤害** |

## 四、玩家触及距离（手的长度）

**正常史蒂夫能摸到身前 5 格**（原版 `BLOCK_REACH` 是 4.5，取整 5）。

| 境界 | 增加 |
|---|---|
| 练气 / 筑基（1~2） | 不增加（5 格） |
| **金丹（3）** | **+1** |
| 元婴 / 化神（4~5） | 不增加 |
| **道印（6）** | **+1** |
| 飞升（7） | 不增加 |
| **仙人（8）** | **+1** |
| **仙人之后的每一个境界** | **每境 +1** |

即：帝境 +2、鸿蒙 +3（相对仙人）。

**实现**：Forge 的 `BLOCK_REACH` / `ENTITY_REACH` 是**属性**（`ForgeMod.BLOCK_REACH`），
用 `AttributeModifier` 加即可 —— **注意属性上限已经解除**，但这两个属性新加时要确认
`maxValue` 够用。

## 六、必须守住的既有约束（每条都踩过）

1. **属性上限已解除**（`AttributeCaps.relax()`）；新加 `BLOCK_REACH`/`ENTITY_REACH` 要确认不被截断
2. **客户端也要拿到数值** —— 领域的特效是客户端渲染的
3. **怪物伤害软上限 35%** 不能绕过 —— **但领域效果是"环境伤害"不是"怪物攻击"**，
   要判断清楚走哪条路（建议领域伤害**不走**那个软上限，否则百分比效果全废）
4. **`RegistryObject.get()` 不能在 mod 构造阶段调用**
5. **`data/**` 的 JSON 写错会让服务器起不来** —— 改完必须真跑服务端
6. **法术/领域伤害用 `magic()` 而不是 `lightningBolt()`** —— 后者带 `BYPASSES_ARMOR`，
   我们渡劫那次就因为它变成"雷劫必死"
7. **新按键必须同时补 `key.hongmeng.*` 与 `key.categories.hongmeng`** 的 lang
8. **离线验证器不能碰注册表**
9. **用了 `FlyingMoveControl` 就必须注册 `FLYING_SPEED`**

## 八、首领百分比规则的最终口径（玩家已确认 = B）

玩家已确认选 **(B) 封顶在 2%**。

### 规则（单一写法，可断言）

```
对首领的百分比伤害 = min(本次要结算的百分比, 2.0)
```

| 效果 | 普通怪 | 首领 |
|---|---|---|
| 金 冲击波 | 30% | **2%** |
| 雷 三连 | 10% | **2%** |
| 冰 爆炸 | 10% | **2%** |
| 风 十次 | 10% | **2%** |
| 土 秒杀 | 秒杀（头目以下） | **2%** |
| **火 1%/秒（持续）** | 1%/秒 | **1%/秒（不变）** |
| **水 1%/秒（持续）** | 1%/秒 | **1%/秒（不变）** |

> **为什么持续型不跟着变成 2%**：字面理解"固定 2%"会让火/水对首领变成
> **每秒 2%（50 秒必死）**，反而比普通怪的 1%/秒**更狠**，逻辑上讲不通。
>
> 用 `min(p, 2.0)` 这一个写法就自然统一了：
> 一次性效果传 30/10 得到 2.0，持续效果传 1.0 得到 1.0。
> **规则单一、可断言、以后加新元素不会漏。**

### 首领的定义

`MobRank.OVERLORD`（首领）。注意**头目是 `BOSS`**，土的秒杀对
**BOSS 及以下都生效**（"秒杀头目以下的怪物"中的"头目"= `BOSS`，
即 CAPTAIN 及以下被秒；BOSS 与 OVERLORD 走百分比规则）。

> 这一处原文有歧义（"秒杀头目以下的怪物"），本规格按
> **"低于 BOSS 的品阶被秒杀，BOSS 与 OVERLORD 走 2%"** 实现。

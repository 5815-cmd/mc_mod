# 战斗手感（Combat Feel）规格 —— 压迫感 / 爽感 / 刺激感 / 华丽宏大

> 玩家要求：**"我的战斗系统一定要有压迫感爽感刺激感华丽宏大像真正的仙"**。
>
> 参考方向：游戏手感设计里的 **"juice / game feel"** 工具箱
> （[A Formal Ontology of Combat Feel](https://digitalcommons.lmu.edu/etd/1380/)、
> [awesome-gamedev-agent-skills 的 game-feel 条目](https://github.com/gamedev-skills/awesome-gamedev-agent-skills)），
> 以及仙侠小说里"压迫感"的写法（境界压制、气场、天地变色）。

---

## 零、核心认知：**"爽"不等于"粒子多"**

这是最容易做错的地方。**堆粒子只会卡，不会爽。**

真正让人爽的是这几件事，按**性价比**排序：

| # | 技术 | 为什么有效 | Minecraft 能不能做 |
|---|---|---|---|
| **1** | **顿帧（hitstop）** | 命中瞬间**双方冻结几帧**——这是**单项收益最大**的手法 | ✅ 冻结实体（清速度 + 短暂免伤 tick） |
| **2** | **屏幕震动** | 让"打中了"这件事通过**镜头**传达到玩家身上 | ✅ `ViewportEvent.ComputeCameraAngles` |
| **3** | **命中闪白** | 目标被打瞬间变白/变红 | ✅ 原版 `hurtTime` 已有红闪，可加强 |
| **4** | **击退位移** | 物理上的"打飞了" | ✅ `knockback()` |
| **5** | **音效分层** | 一次命中叠 2~3 层音（破空 + 撞击 + 余韵） | ✅ 原版音效可以叠放 |
| **6** | **粒子爆发** | **只在命中点**做放射状爆发，不是全场铺 | ✅ |
| **7** | **FOV 冲击** | 大招瞬间轻微拉 FOV | ✅ `ComputeFovModifierEvent` |
| **8** | **伤害数字** | 飘出的数字 | ✅ 客户端渲染（已有血条基建） |
| **9** | **前摇（anticipation）** | **先蓄力再打出去**，比瞬发爽得多 | ✅ 已有 `castTicks` 蓄力系统 |
| **10** | **击杀慢镜** | 最后一击放慢 | ⚠️ 难，跳过 |

### ⚠️ 两条硬约束（否则会翻车）

1. **必须有服务端粒子预算 + 配置倍率**。华丽特效如果每 tick 喷 2000 粒子，
   **mod 直接没法玩**。密度做成 `HongmengConfig` 项，整合包作者能往下调。
2. **顿帧不能真的冻结游戏**（那会卡）。做法是**冻结实体**：
   清速度 + 给几 tick 的免伤 + 客户端表现，绝不 `Thread.sleep` 或暂停 tick。

## 一、顿帧（hitstop）—— 单项收益最大

**规则**：命中造成**超过目标最大生命 X%** 的伤害时，触发顿帧。

| 伤害占比 | 顿帧时长 |
|---|---|
| < 2% | 无（否则平砍一直卡） |
| 2% ~ 10% | **2 tick** |
| 10% ~ 25% | **4 tick** |
| > 25% | **6 tick** |

**实现**：
- 服务端给**攻击者与受击者**都清掉速度（`setDeltaMovement(Vec3.ZERO)`）
- 受击者给 `invulnerableTime` 短暂延长（不影响正常伤害）
- 用**纯数据表**（`CombatFeel.hitstopTicks(damageFraction)`）→ 可离线断言
- **必须防止叠死**：同一实体 10 tick 内不重复顿帧

---

## 二、屏幕震动 —— 让镜头替你说话

**规则**：按伤害占比决定震动强度与时长。

| 来源 | 强度 |
|---|---|
| 普通命中 | 极轻（0.5~1 度，2 tick） |
| 大招命中 | 中（2~3 度，4 tick） |
| 领域爆发 / 雷劫 / 首领出场 | 强（4~6 度，8~10 tick） |

**实现**：`ViewportEvent.ComputeCameraAngles` 里给 yaw/pitch/roll 加噪声偏移。
- **强度做成配置倍率**，并**必须提供一个"关闭屏幕震动"的选项**
  （有人会晕，这是无障碍问题，不是可选项）
- 用**衰减曲线**（`strength * (1 - t/duration)`），不是突然停

## 三、压迫感 —— 仙侠最该做出来的东西

这是"像真正的仙"的核心。**压迫感 = 实力差距的可感知化。**

### 3.1 境界压制视觉

玩家境界**低于**周围强敌时：
- 屏幕**边缘暗化（vignette）**，强度按境界差递增
- **心跳音效**（低频、慢速）
- 准星轻微抖动

> 这条和"怪物境界压制减伤"是**同一枚硬币的两面**：
> 前者让玩家**感觉到**被压制，后者是数值上的压制。
> **必须同时做**，只做数值玩家感受不到。

### 3.2 强者登场

**头目/首领**级别的敌人在附近生成时：
- 天空**短暂变暗**
- **一次低沉的钟声/雷鸣**
- 地面**径向冲击波粒子**
- BOSS 血条**从屏幕上方压下**（已有 `ServerBossEvent` 基建）

### 3.3 领域展开（已有系统的强化）

领域激活瞬间应该是**全场最华丽的一刻**：
- 天象变化（按元素：火=赤云、水=雨幕、雷=雷云、冰=霜降…）
- **一圈从脚下向外扩散的冲击环**
- 地面材质色调偏移
- **音效：一声悠长的"嗡"**

## 四、华丽宏大 —— 法术的三个阶段

**关键：法术要有"起承转合"，不是"啪一下出结果"。**

| 阶段 | 表现 |
|---|---|
| **起（前摇）** | 手上/身前**凝聚**粒子（已有 `castTicks`）· 音效：破空前的"吸气"声 |
| **承（释放）** | 弹道/剑气**带拖尾** · 沿途**残留**粒子 · 音效：破空 |
| **转（命中）** | **顿帧 + 震动 + 放射爆发 + 闪白 + 分层音效**（第 1~6 条一起上） |
| **合（余韵）** | 命中点**缓慢消散**的粒子 · 地面**残留焦痕/冰霜/裂纹** |

### 按元素差异化（复用已有的 8 元素）

| 元素 | 前摇 | 命中 | 余韵 |
|---|---|---|---|
| 火 | 火星汇聚 | 爆燃 + 焦痕 | 余烬飘落 |
| 冰 | 霜花凝结 | 冰晶碎裂 | 地面结霜 |
| 雷 | 电弧跳跃 | 白闪 + 强震 | 电弧余辉 |
| 风 | 气流盘旋 | 切割线 | 落叶盘旋 |
| 金 | 细刃虚影 | 金属火花 | 刃光残留 |
| 木 | 藤蔓破土 | 木刺迸射 | 花瓣散落 |
| 水 | 水珠汇聚 | 水幕炸开 | 涟漪扩散 |
| 土 | 碎石悬浮 | 尘爆 + 地裂 | 沙尘沉降 |

## 五、必须守住的既有约束

1. **伤害用 `magic()` 不用 `lightningBolt()`** —— 后者带 `BYPASSES_ARMOR`，
   渡劫那次就是被它搞成"雷劫必死"
2. **领域伤害不走 35% 软上限** —— 那条是给怪物攻击用的，领域百分比走它会全部作废
3. **客户端也要拿到数值** —— 震动、飘字、vignette 全是客户端
4. **`RegistryObject.get()` 不能在 mod 构造阶段调用**
5. **新按键必须同时补 `key.hongmeng.*` 与 `key.categories.hongmeng`**
6. **顿帧绝不真的暂停游戏 tick**
7. **屏幕震动必须可关闭**（无障碍）
8. **粒子必须有预算上限 + 配置倍率**

## 七、判断标准（做完了怎么知道成不成功）

**一句话自检**：**关掉粒子，还剩多少"爽"？**

- 如果关掉粒子就不爽了 → **说明全靠粒子在撑，是假的爽**
- 如果关掉粒子仍然"打得有分量" → **说明顿帧/震动/击退这些骨架做对了**，
  粒子只是锦上添花

这条自检应该写进验收标准。**粒子是化妆品，顿帧和震动是肌肉。**

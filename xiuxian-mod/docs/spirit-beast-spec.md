# 灵兽 / 坐骑 系统 —— 设计规格

> 依据玩家要求"看看网上那个 rpg 整合包什么的还有模组增加内容，比如坐骑，龙啊什么的"。
> 调研对象见文末。所有设计都是**自研**，不复制任何 mod 的素材或代码。

## 一、调研到的核心模式

| 模组 | 关键设计 | 可借鉴点 |
|---|---|---|
| [Ice and Fire](https://www.curseforge.com/minecraft/mc-mods/ice-and-fire-dragons) | **猎 → 偷蛋 → 孵化 → 驯服 → 骑乘** 的完整闭环；龙守宝藏与蛋；龙可穿**护甲**；内置**图鉴** | 闭环设计；"蛋"作为稀有战利品 |
| [Dragon Mounts: Legacy](https://www.curseforge.com/minecraft/mc-mods/dragon-mounts-legacy) | 末影龙蛋孵化成不同**品种**，数据包可定制 | 品种/元素分化 |
| [Wyrmroost](https://www.curseforge.com/minecraft/mc-mods/wyrmroost) | 每种龙**为特定职能而生**——战斗型、速行型、地面型；"不只是长得不同，**玩法也不同**" | **职能分化**，别做一堆只会飞的同质坐骑 |
| [Mythic Mounts](https://www.curseforge.com/minecraft/mc-mods/mythic-mounts) | 轻量；**召唤法杖**管理坐骑；**跟随/停留/游荡**指令 | 收纳与指令是刚需，不是附加 |
| [Dragon Survival](https://www.curseforge.com/minecraft/mc-mods/dragons-survival) | 扮演龙；**成长阶段** | 成长阶段 |
| [Hiccup's Legacy](https://www.curseforge.com/minecraft/mc-mods/hiccups-legacy) | 用特定食物驯服；**主/副两种攻击** | 双攻击模式 |

**最重要的一条**（来自 Wyrmroost）：**别做一堆只会飞的同质坐骑**。
每个灵兽要有自己的职能，否则玩家只会用最强的那一只。

## 二、本 mod 的修仙化转译

| 通用做法 | 本 mod 的做法 | 理由 |
|---|---|---|
| 用食物驯服 | **把妖兽打到虚弱（<25% 生命）再上「契灵符」** | 复用已有的 10 种妖兽，不需要为每种灵兽再造一个野生版本；也符合"以力服之"的仙侠逻辑 |
| 坐骑召唤杖 | **灵兽袋**（物品）——收纳/放出 | 仙侠标配；且能解决"坐骑走丢/卡住"的经典痛点 |
| 成长阶段 | **幼年 → 成年 → 化形**，靠喂**妖丹**成长 | 给"妖丹"一个真正的用途 |
| 坐骑护甲 | **灵兽护甲**（骑乘时给灵兽加护甲） | 复用已有的护甲数值思路 |
| 图鉴 | 并入已有的**修行录**面板新开一页 | 不新增界面 |

## 三、灵兽清单（按职能分化，不是按稀有度堆叠）

| id | 中文 | 来源妖兽 | 职能 | 骑乘 |
|---|---|---|---|---|
| `spirit_steed` | 灵驹 | 新（温顺，野外可驯） | **地面速行**：速度最快的陆地坐骑，可二段跳 | ✅ 地面 |
| `contract_wolf` | 契约灵狼 | `spirit_wolf` | **战斗协助**：主动攻击敌对生物，伤害随主人境界 | ❌ |
| `contract_eagle` | 契约雷鹰 | `thunder_eagle` | **飞行**：中等速度，能悬停 | ✅ 飞行 |
| `jiaolong` | 蛟龙 | `void_serpent` | **飞行 + 战斗**：最稀有，飞得快、能喷吐、可穿甲 | ✅ 飞行 |

**关键平衡**：
- 灵驹 → 地面最快，但**不能飞**
- 雷鹰 → 能飞，但**脆、载重低（不能带箱子）**
- 蛟龙 → 全能，但**契约门槛高**（需要击败虚空裂隙的头目）

**飞行坐骑消耗主人的灵力**（和御剑同一条灵力池）——这样"坐骑"与
"御剑飞行"构成真实取舍：坐骑更快但要契约成本，御剑随时可用但更慢。

## 四、交互设计

### 契约流程
1. 把目标妖兽打到 **<25% 生命**（它身上会出现虚弱粒子）
2. 手持**契灵符**右键
3. 成功率按境界差与灵根品质计算；失败消耗符纸并激怒它
4. 成功后显示"契约成立"，灵兽进入**幼年**阶段

### 灵兽袋
- 右键灵兽 → 收进袋子（记录 NBT）
- 右键空地 → 放出
- 潜行右键 → 打开**灵兽名册**（列表，可改名/查看状态）

### 命令（潜行 + 右键循环）
**跟随 → 停留 → 游荡**（对齐 Mythic Mounts 的做法，玩家熟悉）

### 骑乘
- 空手右键灵兽 → 骑上
- `WASD` 控制；飞行坐骑**空格上升 / Shift 下降**
- 下马：潜行
- 骑乘时**消耗主人灵力**（飞行坐骑）

## 五、必须守住的既有约束

1. `RegistryObject.get()` 不能在 mod 构造阶段调用
2. 怪物伤害软上限 35% 不能绕过
3. 客户端要拿到数值（灵力条、骑乘状态）
4. `data/` 下的 JSON 写错会让**服务器起不来**——改完必须真跑服务端
5. 离线验证器不能碰注册表
6. 新增按键必须**同时**补 `key.hongmeng.*` 与 `key.categories.hongmeng` 的 lang
   （这个坑踩过**两次**了）

## 六、优先级（如果做不完，按这个顺序砍）

- **P0**：契约机制 + 灵兽袋 + 一种地面坐骑（灵驹）+ 一种飞行坐骑（雷鹰）
- **P1**：蛟龙（龙坐骑）+ 灵兽护甲
- **P2**：成长阶段 + 图鉴页 + 改名

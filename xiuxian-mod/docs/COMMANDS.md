## 按键终表（设置 → 按键 → 鸿蒙修仙，应有 **14 条**）

| 键 | 作用 |
|---|---|
| `R` | 打开修炼面板 |

> **起飞有两种按法**：`H` 键，或者**空中双击空格**（300ms 内连按两次）。
> 两条路走同一个请求包，起落都由服务端按境界裁决；双击只在地面以外计数，
> 所以站着连跳两下不会误触发。

> ⚠️ **`T`/`Y` 是从 `V`/`C` 挪过来的**（腾给法术槽）。

## 出问题时报什么

| 现象 | 给什么 |
|---|---|
| 数值不对 | `/hongmeng attrcap` + `/hongmeng debug` **完整截图** |
| 挖掘速度不对 | 对着方块跑 `/hongmeng debug`，发那三行 |
| 贴图糊了/错位 | **哪个物品/怪物** + 截图 |
| 界面崩了 | `logs/latest.log` **整个文件** |
| 游戏起不来 | **`logs` 整个文件夹**（尤其 `debug.log`） |
| 坐骑不对 | **偏高还是偏低** + 骑的什么 |
| 按键缺失 | **少了哪个键** |

> **崩溃日志**：曾有过一次日志**断在半行、无 Java 异常、无 crash-report**，
> PCL 分析器也报 0 错误——那种情况**整个 logs 文件夹**才有用。

## ⚠️ 堆叠上限：**1024 做不到，已发 127**

反编译证据（`javap`）：

```
ItemStack.save():  getfield count:I → i2b → putByte("Count", …)   ← 窄化成 1 字节
FriendlyByteBuf.writeItemStack():  getCount() → writeByte(I)      ← 也是 1 字节
```

NBT 往返实测：**127 完好**、`128 → -128`、`300 → 44`、**`1024 → 0`**。

**1024 回读 = 0**，而 `count == 0` 时 `isEmpty()` 为真 → **整堆东西下线再上线后静默消失，日志里一个字都没有**。

所以只发 **127**（有符号字节顶），且**只作用于本模组 14 件材料**（灵叶/道印/纪元令/灵铁锭/灵晶/空冥精/血珞精/血罗果/空冥石/神霄令 + 6 片花瓣）。原版物品一个没动。

**想更保守**：`config/hongmeng-server.toml` 的 `[stack] materialStackSize` 调回 64（零风险）。
